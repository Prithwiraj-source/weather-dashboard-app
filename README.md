# Weather Dashboard App

## Description
This web application allows users to check real-time weather information for any city. It fetches data from a public API and displays it in a user-friendly interface.

## API Used
OpenWeather API

##  Features
- Search weather by city name
- Display temperature, humidity, and weather conditions
- Responsive design

##  Technologies Used
- HTML
- CSS 
- JavaScript (ES6)
- Fetch API

##  How to Run
1. Clone the repository
2. Open index.html in your browser
